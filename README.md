# Aether

A chat app for iPhone with direct messages and community channels.

## Features

- Unread message counts in the chat list and Chats tab.
- Online and last-seen status for direct conversations.
- Search message text across conversations and channels you can access.
- Send a photo with an optional caption in direct messages and channels.
- Account settings, friends, communities, and owner moderation tools.

## Compatibility

The iOS app supports iOS 13 and later.

The chat, unread, search, and presence features use the Aether API and its Neon Postgres database.
